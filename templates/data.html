Grain: line items versus orders

One row is one order line item, but the delivery outcome belongs to the order. All {{ '{:,}'.format(analytics.counts.n_orders) }} orders carry exactly one value of Late_delivery_risk, Shipping Mode and shipping date across their line items — the {{ '{:,}'.format(h.n_rows) }} rows are repeated measures, averaging {{ '%.2f'|format(h.n_rows / analytics.counts.n_orders) }} lines per order.

This drives two decisions elsewhere in the application: statistical tests run at the order grain, so a three-line order does not count three times toward one delivery outcome; and the train/test split is grouped on Order Id, so no order appears on both sides.
